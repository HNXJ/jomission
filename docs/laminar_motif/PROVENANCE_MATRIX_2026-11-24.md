## 1. Ruling

> JaxFNE >=0.5.8 is the mandatory minimum version, not an exact-version constraint. Rationale: versions before 0.5.8 were unreliable in core functionality; 0.5.8 was the first sufficiently trusted baseline. The requirement sets a minimum reliability floor, not an obligation to execute exclusively on 0.5.8. Application: JaxFNE 0.5.8 = minimum admissible version. JaxFNE 0.5.9 = admissible for E0 and E1b under their recorded seals. Versions below 0.5.8 = inadmissible. Exact-version reproducibility = still required for each run. Scientific acceptance = requires all other experiment-specific gates. Reconciliation: update the authority documents to distinguish the global minimum (>=0.5.8) from experiment-specific version pins; preserve historical records and the original seals. Do not read the ruling as proof that 0.5.9 results reproduce 0.5.8 results; each result must retain its exact dependency version and provenance.

Source: the workflow task text of 2026-11-24, quoted verbatim.
