## 2. Applicable schema: not defined

Item 34 cannot score 2 yet. Two parts are missing:

- No schema says which provenance fields a receipt must carry. Of the 199 unsealed receipts, 150 name neither a
  generator nor a hash. Some of them are summaries or ledgers, not execution receipts, and nothing in the repo says
  which is which.
- The "names generator" test is a key-name match (`script`, `generator`, `runner`, `module`, ...). It is a heuristic,
  not a check that the named file exists or matches.

## 3. The "10 missing paths" claim: retracted

The packet to the audit worker said the expected count of JSON files naming a missing generator path was 10. The
repo has no source for that number. The figure came from the packet, not from any file or measurement. The
classifier finds no such figure. This audit does not use it.
