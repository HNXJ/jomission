## 1. Question

Do independently measured macaque SST and PVALB interneuron distributions show the SST/PVALB ratio rising from
superficial to deep layers, as LANSA prescribes (S 0.25, M 1, D 2; `jomission/laminar/caminos_stack.py:30`)?
This is an independent test of a prescribed composition, not a fit: no anatomical value feeds back into the model.

## 2. Estimand, contrast, hypothesis

- Ratio per animal a, area j, module l: R(a, j, l) = N_SST(a, j, l) / N_PVALB(a, j, l), counts of cells assigned
  to the SST and PVALB inhibitory types in module l, from the same sections (shared denominator).
- **Primary contrast:** Δ(a, j) = log2 R(a, j, D) - log2 R(a, j, S).
- **Hypothesis (LANSA):** Δ > 0. Prescribed magnitude: log2(2 / 0.25) = 3.0 (an 8-fold rise).
- Secondary: log2 R(D) - log2 R(M) and log2 R(M) - log2 R(S) where an L4 exists; prescribed 1.0 and 2.0.

## 3. Layer mapping (declared before extraction)

LANSA modules (`scripts/lansa_module_density.py`): S above mid-L4 - 0.175, M within ± 0.175, D below + 0.175.
Mapped to cytoarchitectonic layers as labeled in the source:

| Module | Layers | Notes |
|---|---|---|
| S | L2, L3 (L2/3) | L1 excluded from the primary contrast (few PVALB cells; ratio unstable); reported separately |
| M | L4 (all V1 sublaminae 4A, 4B, 4Cα, 4Cβ) | missing in agranular or dysgranular areas; never interpolated |
| D | L5, L6 | |

If the source labels layers differently (e.g. L2-L4 merged), the mapping is fixed by the rule "S = supragranular,
M = granular, D = infragranular"; an area whose labels cannot be mapped by that rule is missing.

## 4. Areas

Target: the 11 LANSA areas (V1, V3, V4, MT, MST, LIP, TEO, PMD, 7A, 8A, PFC). The area-to-source-label table is
written from the source's region list (names only, no counts) and committed before counts are read. An area
with no matching label is missing. Results are per area; no pooling of V1 with association cortex before
heterogeneity is tested (§6).

## 5. Unit of inference and uncertainty

- Biological replicate: **animal**. Area is nested within animal. Cells, spots, bins and sections are never
  independent replicates.
- Sampling uncertainty: within animal and area, a bootstrap over sections (or over cells only if section
  identity is unavailable, labeled as such), 2000 resamples, seed 0.
- Biological uncertainty: spread of Δ across animals, reported per area with n animals.
- Expected n is about 3 animals (to verify). With n = 3 a one-sided sign test cannot reach p < 0.05 (minimum
  p = 0.125), so the primary readout is descriptive and the decision rule below is pre-set, not a p-value.

## 6. Decision rule (per area)

| Outcome | Rule |
|---|---|
| CONSISTENT | Δ > 0 in every animal with data, and every animal's 95% sampling interval excludes 0 |
| CONTRADICTED | Δ < 0 in every animal, intervals excluding 0 |
| INCONCLUSIVE | anything else, including n = 1 |
| MISSING | no data for S or D |

Magnitude, separately: the animal-mean Δ against the prescribed 3.0, reported with its interval. Agreement in
direction does not imply agreement in magnitude.

Across areas: the count of CONSISTENT / CONTRADICTED / INCONCLUSIVE / MISSING areas. Heterogeneity: a
mixed model Δ ~ 1 + (1 | animal) + area is fitted only if ≥ 2 animals per area in ≥ 5 areas; otherwise
heterogeneity is reported descriptively (range of area means). No pooled claim before this step.

## 7. Required controls

1. **Denominator:** report absolute SST and PVALB densities (cells per mm³, or per mm² of section with the
   thickness stated) per module, so a ratio change can be attributed to SST, PVALB or both.
2. **GABAergic restriction:** counts use only cells in the source's GABAergic/inhibitory class; record whether
   any SST-expressing or PVALB-expressing excitatory cells exist and confirm they are excluded.
3. **Area specificity:** §4 and §6.
4. **Independent assay:** compare the SST laminar profile with the 1987 *J Neurosci* SST-28 immunostaining study
   (inventory #3) in the areas both cover: the module with the most SST labeling, and whether D > S.
   Disagreement is reported; neither source overrides the other.
5. **Assay distinction:** transcriptomic cell-type abundance (Stereo-seq/snRNA-seq calls) is never reported as
   protein-positive cell density, and vice versa.
6. **Null check of the pipeline:** before the real contrast, run the extraction on a permutation of layer labels
   within sections; Δ must center on 0 (a pipeline that cannot return 0 proves nothing).

## 8. Secondary outcomes

Absolute SST, PVALB and VIP densities per module and area, where the source supports them. VIP is reported
descriptively only; it has no prescribed LANSA value.

## Amendment A1 (2026-11-16, before any quantitative value was read)

Reason: independent review of `7045b642` returned REVISE (1 blocker, 4 major). Each item below supersedes the
section it names; the original text stays as the record. No Chen 2023 value had been read when A1 was written.

- **§6 decision rule (blocker).** Minimum effect δ_min = 1.0 (a 2-fold rise of SST/PVALB from S to D; the
  prescribed value is 3.0). CONSISTENT: every animal's sampling 95% interval lower bound ≥ δ_min **and** the
  range of Δ across animals (n ≥ 2) lies above 0. CONTRADICTED: every animal's upper bound ≤ 0 and the range
  across animals lies below 0. With n = 1 animal for an area the outcome is at most INCONCLUSIVE. Magnitude is
  reported against 3.0 as before. δ_min is pending owner confirmation; if changed, the change is dated before
  extraction.
- **§5 / §6 statistics (minor).** Primary readout is the A1 rule above. The mixed model is exploratory only.
- **§3 layer mapping (major).** Primary contrast is D vs S; M contrasts are secondary. Each area's layer
  boundaries are taken from the source's own layer annotation and recorded per area. Sensitivity analysis
  (pre-set): S = L2/3 without its deepest third is not possible on labels alone, so the sensitivity contrast
  uses S = L2 only (where L2 and L3 are labeled separately) and D = L6 only; reported beside the primary.
  L1 exclusion stands; its effect is reported (Δ recomputed with L1 in S, secondary).
- **§3 V1 (major).** V1 sublaminae (4A, 4B, 4Cα, 4Cβ) are reported separately; the V1 M estimate is
  secondary only. The V1 primary contrast (D vs S) is unaffected.
- **§4 / §3 forking paths (major).** Before any count is read, commit: (i) the area-to-label table from the
  region list, with this fixed procedure for unmappable labels: a LANSA area maps to a source label only by an
  exact or documented synonym; subdivided labels (e.g. PFC subfields) are each kept separate and the LANSA area
  is MISSING unless one subfield matches its LANSA sampling site as recorded in the LANSA preprint; (ii) the
  L2/L3 merge rule (merge when the source labels L2/3 as one layer, else sum L2 and L3 counts); (iii) the SST and
  PVALB type assignment: the source's own published cell-type labels at the finest level that names SST or
  PVALB inhibitory types, with the taxonomy version recorded; no re-clustering.
- **§7.2 GABAergic gate and counts (major).** Only cells whose source class is GABAergic/inhibitory count.
  Minimum per animal × area × module: 10 SST and 10 PVALB cells; below that the module is MISSING. A zero count
  cannot occur above the minimum, so log2 R is always defined; no pseudocount is added.
- **§7.4 cross-check (minor).** Qualitative: for areas covered by both sources (named in the extraction
  record), compare the module with most SST labeling and the sign of D vs S.
- **§7.6 null (minor).** Pass criterion: across 200 within-section layer-label permutations, the median Δ lies in
  [-0.1, 0.1] and the central 95% of permutation Δ contains 0. A failed null stops the analysis.

## Amendment A2 (2026-11-16, before any quantitative value was read)

Reason: re-review of `74891961` (REVISE: one major, three minor). Supersedes the parts of A1 it names.

- **NOT TESTABLE outcome.** If cells cannot be assigned to animals, or fewer than 2 animals pass the count
  floor in every area, the study outcome is **NOT TESTABLE**: a statement about the source, not a finding about
  SST/PVALB, and never reported as a null or as INCONCLUSIVE evidence.
- **Type assignment.** All source clusters under the SST inhibitory parent are summed as SST; likewise PVALB.
  Clusters co-labeled with both parents are listed and excluded from both.
- **Animals after the floor.** n counts only animals that pass the 10-cell floor in both S and D for that area;
  n = 1 gives INCONCLUSIVE, n = 0 MISSING.
- **Cell-bootstrap flag.** A CONSISTENT or CONTRADICTED call whose sampling intervals come from the cell-level
  fallback bootstrap (no section IDs) is reported with the flag "sampling uncertainty understated".
- **Depth-bin link.** The model's S/M/D are depth bins around mid-L4 (± 0.175 normalized depth); the source
  gives layers. The test compares layer modules with the prescribed module ratios; it does not claim that the
  model bins and the layers coincide in depth. Stated as a limitation in the outcome record.
