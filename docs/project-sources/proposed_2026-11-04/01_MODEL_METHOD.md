# Scientific model, questions and method
JDNA → constructed model → neural state X → H → HDP/plastic parameters Θ → neural source → field/proxy → observation. H is scalar in qualified historical runtime; H is not homeostasis. Functional plastic retention, neural state memory and recurrent dynamical memory are distinct. E/PV/SST/VIP labels are phenomenological reduced-cell classes, not literal molecular identities.

## Historical bounded evidence
Seven recurrence strategies did not yield a reproducible tail: scalar gain, EE gain, slow inhibition/excitation, delay, modularity, tonic-to-recurrent transfer. Clamp E sustain near 3–4 effective drive units versus realized recurrent E 0.01–0.06 in tested assay; these are not native kernel parameter units. Reduced selective EE gain alone produced saddle/saturation; adaptation reshaping plus E-loop support predicted bistability, not verified in JaxFNE.

PV identical tonic input has history-dependent fate (`results/v21_pv_stationarity.json`). M1 single v/u/synaptic-state transplants failed; M2 paired v+u transplant passed in its tested comparison (`results/v21_pv_m2.json`). EI recruitment current decomposition was withheld due to residual mismatch. A ~94–95 ms periodic mode does not prove irregularity or memory.

## Gate requirements
Local operation: per-class rates, active fractions, per-cell ISI irregularity, heterogeneity, stationarity, no pathological synchrony. Recurrent memory: zero-tonic active basin, realized recurrence, matched recurrence-off causal effect, replicated identifiable nonzero perturbation tail; compare M0 no tail, M1 exponential, M2 damped oscillatory; timescale < half observation window. Hierarchy: downstream propagation and causal FF/FB interventions. `log T_k=log T_0+k log g` is a testable hypothesis, not a construction target. Frozen omission T1–T7/Q1–Q15 are not Gen-2 calibration objectives.
